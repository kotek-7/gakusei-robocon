## 2026-10-15：第1巡・第2巡の機能拡充

前回の「実装済み」は出発点として再確認した。グラフの局所表示と物体検索は既存機能として残し、重複する実装は追加していない。

参照したOSS：VS Code **1.95.3** の [`outlinePane.ts`](https://github.com/microsoft/vscode/blob/1.95.3/src/vs/workbench/contrib/outline/browser/outlinePane.ts)。`OutlineTreeSorter` の順序切替、`collapseAll` / `expandAll`、ツリーとエディタの選択連携をソースで確認した。アプリへの適用は以下の通り。

### 第1巡：経路を検討して記録する

- 状態グラフ：ページ移動と選択局面のページ表示を領域のコマンドへ移した。PageUp / PageDownでも100局面ずつ移動し、ページ端で範囲を超えない。非同期取得中に探索・構成・ページが変わった場合は古い操作を反映しない。
- アウトライナー：全展開・全折りたたみを追加。検討記録の枝から保存した経路・時刻を復元し、右クリックで比較A/Bへ送る。候補だけでなく検討結果を同じ階層ビューでたどれる。
- 検討記録：新しい順・試合時刻順・未確認優先、選択局面のみの絞り込み、表示中のJSON保存を追加。並び替えても保存順は変更しない。

### 第2巡：新しい操作から深掘りする

- グラフの表示範囲から「未展開と選択局面」「得点ありと選択局面」を追加。読み込み済みのページだけが対象で、選択局面は必ず残す。表示条件はパネルごとに保存する。
- 局面を絞った後の調査に「直前の局面からの変化」を追加。合流点では比較元を選び、経過秒、得点差、変化した物体の属性と機体の位置・動作を確認する。所在が同じ反転や受け渡し加点も検出する。比較元への移動と差分JSON保存を用意した。
- 記録を読み直す作業から複製を追加。判断を未確認に戻し、経路・範囲・メモを引き継ぐ。ブラウザでメモ入力直後の複製が古いメモを取る問題を発見し、保存待ちの更新後に最新レコードを読んで複製するよう修正した。
- 全展開後に記録へ到達し、全折りたたみ後も各枝の件数を残せることを確認。絞り込み中の全展開・折りたたみは絞り込み解除後の状態に反映する。
