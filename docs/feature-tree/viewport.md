# 3Dビュー

2026-10-14。`docs/ui-reference/blender-godot.md` の #60（追従対象）、#92–94（軸・ズーム・投影）、#301（選択対象／全体表示）と照合。

## レビュー

探索を作成して「試合解析」を開き、機体表から赤BRを選ぶ→追従→青BRへ切り替える→上面へ戻す、平行投影で機体へ寄る→視点を保存する、を対象タスクにした。

既存実装では、追従中に別機体を選んで追従を押すと解除される。上面・保存視点への切り替えは描画側だけ追従を解除し、ボタンの状態が残る。平行投影の「選択対象を中央に表示」は距離だけ変えて拡大せず、保存視点も平行投影の倍率を保持しない。ギズモの軸はキーボードから選べなかった。

## 採用した子機能

- **追従対象の切り替え・解除 — 実装済み。** 選択した別機体への切り替え、同じ対象で解除。未選択時の暗黙の赤TR追従を廃止。視点変更・全体表示・中央表示で追従状態をそろえて解除する。ボタンのツールチップに追従対象を表示。
  - 再レビュー: 選択・追従を既存の機体表と結びつけた。専用対象セレクターは既存表と重複するため優先度を下げて打切り。
- **平行投影のフレーミングと復元 — 実装済み。** 選択対象／全体表示で投影倍率を調整。倍率と投影範囲をレイアウトと保存視点に保持し、古い保存視点も読み込む。
  - 再レビュー: 距離によらず機体へ寄り、全体へ戻る操作を対象にする。レンズ数値入力はこのタスクに不要なので打切り。
- **視点操作のコマンド統一とキーボード操作 — 実装済み。** 軸、ズーム、投影、計測、表示メニューを既存コマンド経由に統一。軸はTabで選び、Enter／Spaceで実行。カメラを動かすコマンドは保存状態も更新する。
  - 再レビュー: マウス・キー・メニューで同じ操作へ到達する。新しい専用ショートカットは既存テンキーとパレットで足りるため打切り。

## 今回採らない機能

- 過去・未来の機体ゴースト: 比較Bゴーストと軌跡が既にある。区別と設定が増えるため、実際の経路比較で必要になるまで優先度を下げる。
- カメラ自動切替: イベントへのジャンプ後に選択対象を中央表示できる。編集・削除・優先規則まで増やす根拠がなく打切り。
- 経路網・ラベルの全面変更: 今回の追従・視点タスクの問題と独立しているため未着手。
