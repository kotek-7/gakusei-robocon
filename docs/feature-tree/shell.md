## 2026-10-15 再帰レビュー：検討記録と領域切替

- ルールと目的：180秒の搬送・建設・反転を、同じ相手手順で比較する。記録の「採用候補」は利用者の判断であり、計算による最適性や保証ではない。
- 全体の確認：局面選択とA/B比較はあるが、理由と経路・時刻を一緒に残す場所がない。
- 第1巡：独立エディタ・ワークスペース「検討記録」と「検討」メニューを追加。経路、選択対象、時刻、再生範囲を保存し、見出し、メモ、判断を編集する。ブラウザ保存と既存バックアップに含める。
- 第2巡：記録が増えた後の確認作業から、全文検索、判断による抽出、表示中のコピー、記録からA/Bへの登録、削除の取消を追加。新しい記録はフィルターを解除して選択する。
- 第3巡：390pxで左右ドックを同時表示すると読みにくい。領域切替バーを追加し、700px以下では一つの領域を全幅で扱う。レイアウトと各エディタの状態は保持。非表示の3D描画は停止する。
- OSS参照：[Blender space_time.py](https://github.com/blender/blender/blob/main/scripts/startup/bl_ui/space_time.py) の `marker_menu_generic`。マーカーを一覧内の印で終わらせず、移動・編集・削除などの操作対象とする構造を検討記録に応用した。コードは転用していない。
- 採らない案：AIによる作戦の命名・採否決定。利用者の判断を保持するという目的に反するため。共同編集や外部送信は今回追加しない。
- 検証：経路復元中の探索切替を非同期テストで確認。記録と比較・マーカーの同時保存、記録検索、レイアウトを失わない新エディタ表示をテスト。実画面でメモ・判断の再読込、削除取消、A登録、390pxの領域切替を確認。
