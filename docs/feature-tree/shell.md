# 外枠（メニュー・パレット・設定・ステータスバー・レイアウト）

## 作業台の外枠 — 実装済み
使った結果：改修前は文書型の1ページで、ショートカット、右クリック、設定、リンクが一切なかった。
- コマンドレジストリ — 実装済み
  - メニューバー（ファイル、編集、表示、移動、再生、探索、ウィンドウ、ヘルプ） — 実装済み
    - F10 で開き、←→ でメニュー間を移動 — 実装済み
    - 機能を追加するたびに登録からメニューを自動生成 — 実装済み
  - コマンドパレット（Ctrl+Shift+P、F3） — 実装済み
    - 移動モード（Ctrl+P）：候補、マーカー、評価の作戦 — 実装済み
    - 接頭辞：`>` コマンド、`#` 局面、`:` 時刻、`@` 選択、`?` 一覧 — 実装済み
    - 最近使ったコマンドを先頭に表示 — 実装済み
  - キー割当て（エディタ別の scope、重複検出、記録して変更、既定に戻す） — 実装済み
- ワークスペースとドック — 実装済み
  - 分割、サイズ変更（ダブルクリックで均等、キーボードでも可）、最大化、閉じる、エディタ差し替え — 実装済み
  - タブのドラッグ並べ替え、新規、複製、名前変更、初期化 — 実装済み
  - 配置のJSON書き出し・読み込み — 実装済み
  - 切り替えてもマウントを保持（3Dを作り直さない） — 実装済み
  - 打切り：別ウィンドウへの切り離し。理由：Web Lock で計算画面を1タブに限定しているため。
- 設定画面（スキーマから生成、検索、`@modified`、項目ごとの既定戻し） — 実装済み
- ステータスバー — 実装済み
  - 計算の状態、候補探索の経過メーター、停止 — 実装済み
  - 局面と得点、再生位置、選択対象 — 実装済み
  - 通知の未読数、一覧（最大100件） — 実装済み
- 計算終了の通知と「最高点の候補を開く」 — 実装済み
- 集中表示（F11） — 実装済み
- テーマ（システム・ライト・ダーク）、文字の倍率、表示密度 — 実装済み
- URL（探索、ワークスペース、局面、経路、時刻、選択）、戻る・進む（Alt+←→） — 実装済み
