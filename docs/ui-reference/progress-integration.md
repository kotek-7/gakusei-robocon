# 計算進捗の統合確認

2026-10-15。作業ブランチ `codex/computation-progress`。実行サーバーはこのチェックアウトの `web`、ポート4187。

開始操作は共通コマンドで計算パネルを表示する。開始待ちは探索IDごとに管理し、連打・別方式の開始・削除・複製を抑止する。最終保存中も開始操作を無効にする。停止要求は同じ探索IDへ送る。

## 確認した経路

- 条件作成から候補探索を開始すると計算パネルが開き、今回の経過・時間枠・前回保存時刻を表示する。画面内の停止で「操作により停止」「保存済み」と計算履歴へ移る。
- 終盤局面の候補探索は5候補で対象範囲終了。これは全作戦の網羅を意味しない。
- 全探索は今回1,000行動組を処理し「指定の行動組数に到達」「1,000 / 1,000行動組」「保存済み」を表示する。
- 評価は準備後に構成1件の集計を完了し、保存完了表示と評価結果への入口を表示する。
- 再読込後は一時的な「今回の計算」を復元しない。保存結果は方式選択から参照する。
- 1280pxと700pxの画像を目視。700pxの計算パネルはclientWidth/scrollWidthとも692px。最新の今回/累計・保存時刻の文言はDOMでも確認した。

全141テスト成功。型検査を含むビルド成功。保存遅延・保存失敗・初期保存中の二重開始/停止はRuntime回帰テストで確認した。Impeccable検出は変更したUIに新規指摘なし。既存style.cssの対象外3箇所に太い片側罫線の警告がある。

実ブラウザの3D表示で高負荷になったため、全探索・評価・再読込の統合操作はWebGLを無効にした別ブラウザでも確認した。3D自体の変更はない。スクリーンショット取得はフォント待機で一部タイムアウトしたため、操作結果と幅はDOMで別途確認した。
