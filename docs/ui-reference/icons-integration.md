# 非3D領域のアイコン操作

候補、作戦詳細、計算、条件、評価、グラフ、プロパティ、得点、区間、履歴、検討記録、アウトライナー、共通ヘルプとアプリバーを対象にした。

## 選定と配置

既存の16px線画へ記号を追加し、保存・書出し・複製・削除・閉じる・前後移動・絞り込み解除を共通化。候補名、値、指標、条件の名前は読む対象として残す。作戦詳細・追加探索など固有の入口は短名を併記する。

Blender v4.3.0 の `space_dopesheet.py` はヘッダーの追加・削除・順序・フィルターをアイコンにし、パネル内の設定名を文字で表示する。VS Code の検索・デバッグ操作も標準操作を小さなボタンにまとめている。具体的なソースリンクと領域別対応は [候補](icons-candidates.md)、[作戦詳細](icons-strategy.md)、[解析](icons-analysis.md) に記載。

参考PDFの項目95（75–76頁）を画像でも確認。頻出操作のラベルを必要時に表示する構造を採用した。PDFの図は実画面を基にした再構成図であり、各ソフトをローカル操作した証拠とは扱わない。

## 共通部品

`IconButton` は操作名、ネイティブhover説明、キーボードフォーカス時の説明を提供する。説明はmanual popoverでtop layerへ表示し、別のpopoverやdialog内でも隠れない。showPopoverの再入を避けるため次のanimation frameで開く。Escape・blur・scroll・resizeで説明を消す。disabled、ref、既存ハンドラー、押下状態を保持する。

## 統合レビュー

3担当へ領域を分担（委譲1段）。候補5巡、作戦詳細5巡、解析4巡のソース確認後、候補担当が全体の独立レビューを実施した。ブラウザー検証は統合担当が実施。

- 候補一覧から作戦詳細へ移動。相手手順の集約行から2展開の詳細へ進む操作を確認。
- 概要、固定手順、完了結果、動作・時間、得点、実行不可、相手展開、履歴、追加探索を切り替えた。
- 条件の差分表示、区間解析、検討記録を開いて確認。
- 保存条件popover内へTabで移動し、閉じるボタンの説明がtop layerに表示され、Escapeで消えることを確認。最初に発見したpopover再入エラーを修正し再操作した。
- 1440×1000 / 1000×800で画像確認。1000px幅でページ全体の横あふれなし。作戦タブは折り返し表示。
- 新しい共通アイコン操作にaccessible nameの欠落なし。

画面確認後に、領域間で不一致だった3D表示と絞り込み解除の記号を統一。数値入力や業務用語の全面的な記号化は行わない。探索モデルには変更なし。
