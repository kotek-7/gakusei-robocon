# 作戦詳細画面のデザイン確認

確認日: 2026-10-15。既存の Operate 方針に沿った画面追加として確認した。`PRODUCT.md`、`DESIGN.md`、`.impeccable/` は変更していない。この記録は画面固有の判断と検証範囲を残すもので、デザイントークンの新しい正本ではない。

## 目的と画面構成

候補の得点だけでなく、赤TR・赤BRがどこへ移動し、何を取得・受け渡し・設置するかを読める作業面になっている。候補一覧の「作戦を詳しく見る」から、左に作戦詳細、右に既存の3Dとタイムラインを置くワークスペースへ進む。狭い画面では作戦詳細・3Dビュー・タイムラインをタブで切り替える。

最初に機体別の固定指示の内訳と地点を示し、その後に相手待機時の完了結果と番号順の全手順を置く。固定指示と実行結果を同一視せず、それぞれの見出しで区別している。スクロール中も構成・候補・展開と節への移動を残す。節の補足は既存の「?」部品に集約し、メモ欄や「▼詳細」の折りたたみを追加していない。

動作・時間の節は、機体ごとの作業・移動・待機・未記録、区間指定、動作検索、行選択、同じ時間帯の他機体を扱う。得点の節は開始・増加・減少・差引・終了の表と時刻別の変化を扱う。時刻、機体、対象地点から既存3Dへ移る接点があり、数表と描画を照合する既存の操作方針を維持している。

## 既存システムとの整合

白い作業面、細い行境界、青緑の操作と選択、チーム識別の赤青を継承している。新しい装飾カード、影、ブランド色、書体を導入していない。見出し・表・短い操作列で区切り、候補一覧の既存CSSと同じフラットな構成を使う。数値表には等幅数字を指定し、実行記録の選択は背景色に加えてラジオボタンで示す。

新規CSSは既存の `surface`、`line`、`muted`、`accent`、`selected`、`selected-ink`、`focus` を参照している。実行記録の表は最小幅を維持して枠内スクロールし、操作列と候補・展開選択は折り返す。スマートフォンの確認画像では候補名と選択欄が画面幅に収まり、作戦詳細の本文を独立した面として読める。

## 確認した証拠と範囲

- `PRODUCT.md`、`DESIGN.md`、impeccable の document 手順を読んだ。既存の設計文書を更新する依頼ではないため、画面追加の記録をこのファイルに限定した。
- `web/src/editors/strategy-detail/` の画面コンポーネント、CSS、3D移動コマンド、`web/src/app/layout.ts`、候補一覧の導線と既存CSSを確認した。
- `.playwright-mcp/strategy-desktop-final.png` で固定指示概要、全手順、3D、タイムラインの配置を確認した。
- `.playwright-mcp/strategy-mobile-final.png` で狭幅の選択欄、操作の折り返し、エディター切替を確認した。
- `.playwright-mcp/strategy-execution-final.png` で時間配分、検索、選択行、時刻への操作を確認した。
- `.playwright-mcp/strategy-score-final.png` で得点内訳、増減、選択時刻、同時刻の動作記録を確認した。
- `/tmp/strategy-detector.json` は `[]` だった。これは当該検出結果であり、アクセシビリティ全般や動作の完全性を保証するものではない。

この確認は画像とソースによる文書化であり、独立したブラウザ操作、計算検証、追加テストは実施していない。

## 残る差分

固定手順概要の「手順へ」はデスクトップ画像でも2行、スマートフォン画像では3行に折り返される。操作は見えているが、短い操作名の読み取りには改善余地がある。

`DESIGN.md` は本文14px以上を基本としている一方、今回の手順見出しには13px、機体見出しには12pxがある。既存画面にも小さい補助文字はあるが、この追加を本文縮小の新しい規範とはしない。

既存 `.impeccable/design.json` の古さは別途報告済みの事項として保留した。この文書化ではsidecarを再検証・再生成していない。画面追加による配色・階層・構成の重大な不整合は、確認した4枚とソースの範囲では見つからなかった。
