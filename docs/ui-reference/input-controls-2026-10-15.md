# 条件・計算・検討記録の操作部品

2026-10-15。画面をセクションへ分けるだけでは、設定値、対象選択、実行、絞り込みの違いを読めない。今回の変更は各操作の意味に合わせて入力部品を選び直す。アプリ内に説明用の画面は追加しない。

## 調べたOSSの実装

固定タグの実ソースを取得し、以下の実装を読んだ。ツール自体を起動した実機調査ではない。

- [Godot 4.5-stable — editor_properties.cpp](https://github.com/godotengine/godot/blob/4.5-stable/editor/inspector/editor_properties.cpp#L781): `EditorPropertyCheck` はチェックボックス、`EditorPropertyEnum` は選択肢、`EditorPropertyFloat` は単位接尾辞を持つ数値入力を生成する。すべてを操作ボタンへ変換せず、値の型で編集部品を選ぶ。
- [KiCad 9.0.0 — panel_setup_constraints_base.cpp](https://github.com/KiCad/kicad-source-mirror/blob/9.0.0/pcbnew/dialogs/panel_setup_constraints_base.cpp#L46): 制約の名前、編集欄、mmなどの単位を別要素として行に配置する。数値欄と単位の結び付きを維持する。
- [VS Code 1.100.0 — markersView.ts](https://github.com/microsoft/vscode/blob/1.100.0/src/vs/workbench/contrib/markers/browser/markersView.ts#L149): Problemsはフィルター入力、選択中の種類、絞り込み件数、結果ウィジェットを別に管理する。フィルターは表示を変え、行の操作は対象を開く。
- [VS Code 1.100.0 — outputView.ts](https://github.com/microsoft/vscode/blob/1.100.0/src/vs/workbench/contrib/output/browser/outputView.ts#L53): Outputは出力チャンネルとテキスト・種別フィルターを持つ。計算の種類・出力を選ぶ操作と、その処理を開始する操作を分ける参照とした。

## 要素ごとの判断

| 対象 | 意味 | 採用した部品・配置 | 維持する制約 |
|---|---|---|---|
| 編集するチーム | 同時には片側だけを編集 | 凡例付きのラジオグループ | 反対側へコピーする操作は別ボタン |
| 能力の可能／不可 | 探索値集合が3種類 | 不可固定・可能固定・両方探索のselect | 空集合は作らない。両方の探索を維持 |
| 搭載数候補 | 複数の個数を同時に含む | 個数ごとのチェックボックス | 最後の1候補は外せない |
| 数値候補の採否 | 数値そのものとは独立した包含指定 | 各数値の横のチェックボックス | 赤青別の採否と共通数値を分離 |
| 数値スペック | 仮定した物理量 | 右寄せ数値入力＋m/s・秒の接尾辞 | 元の正数範囲と検証を維持 |
| 表示中の数値候補を揃える | 行範囲への一括設定 | 表のcaption内に候補プリセットselect | 表示した項目のみ変更、一回でundo |
| 行の復元・反対側へ揃える | その属性だけの編集操作 | 属性名の横の小さいテキスト操作 | 全体実行ボタンと見た目を分離 |
| 能力検索・変更のみ | 表示条件 | search入力とチェックボックス | 探索条件自体を変更しない |
| 初期配置・裁定の選択 | 一つの規則値を指定 | 名前とselectを揃えた属性行 | ルール出典は既存Helpから到達 |
| 組合せを1候補へ固定 | 値を選んで次元を縮める | 各行の値選択select | 候補数・固定後の構成数は読取値 |
| 計算種類 | 見ている処理チャンネル | 上部のselect | 選ぶだけでは処理を開始しない |
| 探索制限時間 | 次の実行に渡す設定 | 開始ボタンの隣のselect | 10秒〜24時間、保存済み設定を利用 |
| 開始・停止 | 実処理の制御 | 開始を明示的な実行ボタン、停止は独立ツール | 登録済みコマンドのenabledを使用 |
| 構成ごとの計算結果 | 結果の走査と対象への移動 | インラインの数値表、構成IDはリンク形の操作 | 候補を開く既存コマンドを維持 |
| 計算履歴 | 過去の実行ログ | 展開できる表、更新あり／全件はチェックボックス | 終了理由select、同時間で再開も維持 |
| 検討記録の一覧 | 保存した対象の選択 | 時刻・名前・判断を持つフラットな行 | 選択行を明示、通常のTab操作に対応 |
| 記録の判断 | 三択の値 | 未確認・採用候補・見送りのラジオ | 保存処理は既存review.update |
| 記録の復元 | 保存した対象を開く | 詳細上部の「この記録を表示」 | 経路・時刻・区間を復元、自動再生はしない |
| 比較への割当 | 保存対象をA/Bに使う | 「比較に使用」内のA/B操作 | 空経路は割当不可 |
| 複製・削除 | 記録の管理 | 詳細下部で分離 | 削除は既存確認フローを維持 |
| 選択局面のみ | 一覧の真偽フィルター | チェックボックス | 記録や現在局面を変更しない |
| コピー・JSON | 表示対象の出力 | 書き出しの開閉内へまとめる | 絞り込まれた対象だけを書き出す |

機能の入口を減らすための一律のタブ化や、枠線を消すだけの変更は採用しない。型のある入力、出力表、選択行、文脈操作、実行ボタンを区別する。
