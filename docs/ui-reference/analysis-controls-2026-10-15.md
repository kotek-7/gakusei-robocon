# 解析画面の操作部品と配置

確認日: 2026-10-15。以下はアプリ内の説明画面ではなく、実装時の判断記録です。枠付きボタンを減らすこと自体を目的にせず、設定値、選択、移動、実行の違いが操作部品から分かるようにしています。

## 調べたOSS実装

- [Blender `space_time.py`](https://github.com/blender/blender/blob/main/scripts/startup/bl_ui/space_time.py): `playback_controls` は移動・再生をアイコンでまとめ、現在時刻と開始・終了を数値プロパティで扱う。`TIME_MT_view` は表示設定を担当し、`TIME_PT_playback` は追加の再生設定をpopoverに置く。区間値を削除アクションのラベルに兼用しない点を採用。
- [Blender `space_view3d.py`](https://github.com/blender/blender/blob/main/scripts/startup/bl_ui/space_view3d.py): `VIEW3D_PT_overlay` / `VIEW3D_PT_overlay_guides` は表示状態をプロパティ行として編集し、適用条件に応じて子操作を無効にする。表示変更ごとに閉じるコマンドメニューから、複数の表示設定を続けて変更できるpopoverへ変更。
- [KiCad `appearance_controls.cpp`](https://github.com/KiCad/kicad-source-mirror/blob/master/pcbnew/widgets/appearance_controls.cpp): `s_objectSettings` と `NET_GRID_TABLE` は対象名・可視状態・色を区別する。レイヤーの高コントラスト方式は `wxRadioButton`、独立する反転表示は `wxCheckBox`。排他的な表示方式と、複数同時に有効にできる表示項目を異なる部品にする点を採用。
- [Godot `editor_inspector.cpp`](https://github.com/godotengine/godot/blob/master/editor/inspector/editor_inspector.cpp): `EditorInspector::edit(Object*)` は編集対象を切り替えてプロパティを再構成する。`EditorProperty::get_minimum_size` はラベル・値・必要な補助操作を区別して幅を計算する。対象名や値をすべて同じコマンドボタンにしない点を採用。

リンクは確認時の開発ブランチ。上記の関数・クラス名を照合し、製品全体がこのアプリと同じ配置であるとは主張しません。

## 要素ごとの判断

| 場所・要素 | 意味 | 実装した部品・配置 | 判断理由 |
|---|---|---|---|
| タイムラインの先頭・末尾・前後移動 | 再生位置の移動 | アイコン群。各アイコンにアクセス可能名とtooltip | 数値設定やモード選択と別の操作であることを表す |
| 再生・逆再生・ループ | 実行と状態 | 再生アイコン、押下状態。ループは独立したトグル | 区間の存在と反復再生を混同しない |
| 再生速度 | 排他的な数値選択 | 現在値を示すselect | メニューを開くまで値の候補が分からない独自ボタンを不要にする |
| 区間の有無 | 解析・再生に共用する選択区間 | checkbox。オンで現在位置から区間作成、オフで区間解除 | 以前の「10–30」を押すと突然区間が消える操作を廃止 |
| 区間の開始・終了 | 数値編集 | 個別のnumber入力。秒の単位を併記 | 値の閲覧と値の変更を一致させる。I/Oの既存ショートカットも存続 |
| 3Dの表示項目 | 独立した可視状態 | 競技場・解析表示のfieldsetにcheckbox行 | 操作ごとにメニューを開き直す手間をなくす。変更時にも競技場が見える |
| 競技場を半透明 | 競技場表示に従属する設定 | 競技場非表示時はdisabled | 適用できない状態を操作前に示す |
| 3Dの視点と保存視点 | 視点への移動 | ドロップダウンメニュー | 一度に一つの視点へ移る操作であり、複数選択の表示レイヤーとは分ける |
| 追従・計測 | 継続する操作モード | 押下状態のあるアイコン | 値のない実行ボタンではなく現在のモードを示す |
| プロパティの局面／機体／物体名 | 対象への移動 | 下線付きテキスト参照 | 表のデータをボタン箱に変えない。Enter/Spaceで移動可能 |
| プロパティの中央表示 | 選択対象に対する操作 | 時刻行にfocusアイコン | 対象の値と混ぜず、対象を見ている位置から実行する |
| プロパティの履歴・区間解析 | 関連する作業領域への移動 | テキスト参照 | 実行コマンドやオン・オフ状態と区別する。重複していた追従は3D側に集約 |
| 局面の表示内容 | 狭いインスペクター内の表示選択 | 現在値付きselect | 四つの枠付きボタン列を置かず、対象の詳細に横幅を使う |
| 得点の両チーム・点差・内訳 | 排他的なグラフ方式 | native radio group | 複数同時オンにできるトグルという誤解を防ぐ。矢印キーで選択できる |
| 得点の再生位置・区間増減 | 排他的な集計対象 | native radio group。区間なしでは区間増減をdisabled | 計算対象を常時示し、別々の説明セクションへ分割しない |
| 得点グラフ上の再生位置 | 連続量の操作 | SVGをアクセス可能なsliderとして公開 | クリックだけでなく左右キー、Shift+左右、Home/Endでも再生位置を指定 |
| 動作履歴の前後移動・CSV | 移動・コピー | 履歴検索の隣にアイコン | 長い同形ボタン列を避ける。各操作のアクセス可能名を保持 |
| スポットの配置図・一覧 | 排他的な表示方法 | native radio group | 表示形式の選択であることを明示 |
| スポットの継続秒数 | 時間区間への移動 | 下線付きの秒数と移動アイコン | 同じ文言を全履歴行へ繰り返さず、比較したい時間を先に読む |
| A/Bの対象設定 | 比較列のデータ割当て | 対応する列見出し内の設定アイコン | 列末尾から離れた共通ボタン列を廃止し、変更先を明確にする |
| A/B交換 | 比較両列への操作 | 差分列見出し内の交換アイコン | 個別のA/B設定と区別しつつ比較対象の隣に置く |
| 点差変化の前後移動 | 時間の移動 | 検索・絞り込みから分離したnavigation行 | 表示条件を変える操作と、再生時刻を動かす操作を混在させない |

## 入力・アクセシビリティ

- checkbox、radio、selectはブラウザ標準のキーボード操作を利用する。
- 表示popoverはHTML Popover APIでtop layerに出し、ドックのoverflowで欠けない。Escapeと外側クリックで閉じられる。変更後も開いたまま。
- 区間入力はEnterまたはblurで確定し、Escapeで元の値へ戻す。片方の値を編集しても反対側の端点を変えない。開始が終了を越えないよう制限する。
- 保存した別の区間や「区間の無効化」状態は導入していない。checkboxを外すと既存の `play.clearRange` と同様に選択区間を解除する。
- 得点グラフの左右キーは0.25秒、Shift併用は1秒、Home/Endは競技の先頭／終了。キーイベントを止めてグローバル移動と二重実行しない。
- `rangeInput.test.ts` で通常編集、端点交差、競技時間外、空欄・非数値・無限大を検証する。
