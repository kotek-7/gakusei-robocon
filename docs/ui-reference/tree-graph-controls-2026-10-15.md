# フィールド階層とグラフの操作

## 参照実装と適用範囲

- [Blender 4.5 Outliner](https://github.com/blender/blender/blob/v4.5.0/scripts/startup/bl_ui/space_outliner.py): ヘッダーの `display_mode`、検索、対象に応じたフィルター、`OUTLINER_MT_context_menu_view` の階層操作を確認。表示対象の切替と選択対象への操作を分離する。
- [Godot 4.5 GraphEdit](https://github.com/godotengine/godot/blob/4.5-stable/scene/gui/graph_edit.cpp): コンストラクターで `top_layer` 内の `menu_panel` に倍率とズーム操作を置き、グリッドのトグルと間隔のSpinBoxを別の部品にする。キャンバス操作をキャンバス内に集める考え方を採用した。右下配置自体は本アプリの判断。

## 個別の判断

| 要素 | 操作の意味 | 実装 |
| --- | --- | --- |
| アウトライナーの表示対象 | 何の階層を操作するか | 競技フィールド／探索データのselect。検索・展開状態とは独立 |
| 機体・保持物・スポット | 現在時刻の物理的な包含関係 | チーム→機体→保持物、建設スポット→積まれた物体、所在→残りの物体。移動すると所属も追従 |
| 階層の行 | 対象選択 | クリックで選択、Enter・ダブルクリックで中央表示。対象操作はコンテキストメニュー |
| 全展開・全折畳み | 階層全体への操作 | 階層ツールメニュー。個々の開閉は行の矢印 |
| 保存視点 | カメラの復元 | 探索データ階層で視点を選ぶと対応カメラを復元 |
| グラフの表示条件 | 局面集合の絞り込み | 上部selectと局面数。探索結果の変更とは区別 |
| 拡大縮小・中央表示 | キャンバスの閲覧 | キャンバス右下の倍率select、アイコン |
| ページ送り | 読み込むデータ範囲 | グラフの下に前後移動と現在範囲／全件数 |
| ノードの移動 | 接続関係の確認 | 左右は表示中の前後接続、上下は同時刻の兄弟。Enter・Spaceで確定。移動だけで再生位置を変えない |
| 遷移 | 選択局面からの分岐 | 選択局面から出る遷移だけをTabの対象とし、全エッジを巡回させない |

全ボタンに枠と背景を付けていた共通CSSは撤去。実行操作には明示的な `action-button`、ツールバーには `tool` を使用する。これは上表の操作構造を補助する見た目の区別であり、枠を外すだけで構造化したとは扱わない。

## 検証

包含関係の変化・検索時の祖先保持、グラフの表示中接続に沿った移動を単体テストで確認。実ブラウザでフィールド階層、グラフの矢印移動→Enter確定、独立した倍率・ページ操作の配置を確認した。
