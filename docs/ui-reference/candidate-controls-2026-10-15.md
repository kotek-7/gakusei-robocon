# 候補・評価の操作単位と配置

2026-10-15。画面内へ説明セクションを追加するための資料ではなく、実装判断の記録。

## 読んだ実装

- [Godot Tree::gui_input](https://github.com/godotengine/godot/blob/master/scene/gui/tree.cpp): `ui_up/down/home/end` は行選択と表示位置を更新し、`ui_accept` は `item_activated` を発火する。選択、展開、ボタン押下は別の入力処理。
- [KiCad DIALOG_DRC](https://github.com/KiCad/kicad-source-mirror/blob/master/pcbnew/dialogs/dialog_drc.cpp): `OnDRCItemSelected` は選択された検査項目を設計対象へ対応付ける。`installLinkHandlers` / `hitTestLink` は本物のリンクにだけ手形カーソルとURL移動を与える。`SetupStandardButtons` の実行・終了とデータ選択は別。
- [Godot EditorInspector::edit](https://github.com/godotengine/godot/blob/master/editor/inspector/editor_inspector.cpp): 選択オブジェクト変更で編集対象を更新し、プロパティ・検索・折りたたみはその対象に従属する。

参照は当日の master の読取。固定リリースの完全な模倣ではない。特にKiCadの自動cross-probeをそのまま適用すると本アプリでは再生経路全体が切り替わるため、一覧の選択と3Dへの反映を分離した。

## 要素別の判断

| 要素 | 操作の意味 | 実装した表現と理由 |
|---|---|---|
| 候補行 | 検査対象を選ぶ | 行全体を選択。上下・Home・End、選択色、ロービングフォーカス。ハッシュは操作ではないためボタンを撤去。Godot Treeの選択に対応。 |
| 候補の主表示 | 候補同士を識別する | 実データの建設・反転順を先頭列に表示。構成番号は独立した短い列。作戦・展開IDは副情報で残し、架空の作戦名を作らない。 |
| 候補の起動 | その候補の経路を再生する | Enter・ダブルクリックで共通最小点差、なければ相手待機の経路へ。単なる選択では現在の再生を変更しない。 |
| 構成フィルター | 候補集合の対象を限定する | ネイティブselect。構成番号と件数を選択肢にし、長いスペックは選択後に表示。 |
| 検索 | 候補集合を絞る | 常設search入力。作戦IDと実際の手順が検索対象。 |
| 件数 | 絞り込み結果を知る | 非操作テキスト。ボタン・カードにしない。 |
| 並び順 | 集合の順序を変える | 表示設定内select。計算の実行ではない。 |
| 検査状況 | 集合を条件で絞る | 表示設定内select。有効条件は一覧上に解除可能な表示を残す。 |
| 共通相手手順 | 同じ相手に限定して照合する | 表示設定内select。相手固定の状態を一覧にも表示。未計算をゼロ扱いしない。 |
| 表示を戻す・条件解除 | 一覧の条件だけを戻す | 軽いテキスト操作。探索を再計算する主ボタンと区別。 |
| 候補書き出し | ファイルを生成する | 明示的な実行ボタン。現在の絞り込みと意味を含めて保存。 |
| 相手展開 | 同じ候補内で検査結果を選ぶ | 点数を並べた小さな選択表。selectに隠れていた得点・実行不可件数を同時比較できる。候補一覧とは別のキーボード移動範囲。 |
| 相手展開の識別 | 計算更新後も対象を保つ | 既存の安定したresponseIdentityを維持。表示順の添字を保存キーにしない。 |
| 3Dに表示 | 選択展開を再生画面へ反映 | 強調した明示的な実行ボタン。Enter・ダブルクリックでも実行可能。 |
| 比較A・Bへ割当 | 選択展開を比較スロットへ入れる | 選択対象の横に小さな割当操作。各候補行に同じボタンを複製しない。 |
| A/B比較へ | 別の作業面へ移動する | 下線付きの軽い移動操作。データIDの見た目と区別。 |
| 選択展開の動作 | 経路の内容を把握する | 選択evidenceのmilestonesを順に表示。候補planと結果経路を混同しない。 |
| 実行不可 | 選択展開の問題を調べる | 該当展開の時刻・機体・理由をその場に表示。モーダルを重ねない。 |
| 探索待ち件数・保証範囲 | 計算の限界を読む | 小さな状態表示と既存の説明入口。操作ボタンにはしない。 |
| 評価の集計対象 | 構成一覧／同条件比較を切り替える | 一つのselect。互いに異なる集計方法を選ぶもので、カードや多数の擬似タブにしない。 |
| 評価の構成行 | 評価対象構成を選ぶ | 候補と同じ行選択操作。ただしEnterは3Dを開かない。構成自体には単一の再生経路がないため。 |
| 比較の相手構成行 | 比較対象となる構成を選ぶ | 行選択で下の集計対象を更新。構成番号を実行ボタンにしない。 |
| 比較基準の探索 | 別探索を基準として指定する | エディタヘッダーのselectを維持。選択作戦ではなく探索全体への設定。 |
| 条件差分フィルター | 比較の成立条件を確認する | チェックボックスと差分表を比較面に直接表示。保存は実行ボタン。生の局面JSONだけ局所的なdisclosure。 |
| 機体スペック | 現構成の補助情報を照合する | 構成に従属するdisclosure。作戦の作業面を消すタブにしない。 |
| 構成検索・絞込・並び順 | 構成集合を扱う | 構成表に隣接する入力とselectを維持。選択作戦への操作とは分離。 |
| 作戦検索・並び順・未決あり | 作戦集合を扱う | 作戦表に隣接する入力・select・checkbox。処理を実行しないので主ボタン化しない。 |
| 分類の分岐 | 共通する先頭動作で集合を狭める | 任意展開の階層フィルター。山括弧アイコンの分岐を選ぶと、その場で経路と一覧の絞り込みが更新。分類を表示するモーダルと二重の「進む／表示」ボタンを撤去。 |
| 分類の祖先 | 上位の集合へ戻る | パンくず状の軽い文字操作。戻った階層の集合へ一覧も追従。 |
| 作戦行 | 構造と点差を調べる | 行選択で下の動作列と点差分布を直接更新。ID・動作数はデータ。行ごとの構造／分布モーダルを撤去。 |
| 作戦の動作構造 | 同時刻の動作群の順序を調べる | 選択作戦について同時刻の群を並べた連続リスト。順番の数値には意味がある。 |
| 作戦の点差分布 | 点差と重みを照合する | 選択作戦の実分布をmeterと数値で表示。装飾的な小グラフではなく、実データの各点差と重みを対応させる。 |
| 代表局面を3Dに表示 | 選択作戦の代表局面へ移動する | 明示的な実行ボタン。Enter・ダブルクリックも対応。識別子クリックと副作用を分離。 |
| 表示構成／作戦の書き出し | 現在集合を保存する | 対象が分かる実行ボタン。表示の絞り込み・評価の意味は保存内容を維持。 |

## 確認

行ナビゲーションの境界・空集合・Enterの分離を単体テスト。候補の共通手順と安定した展開ID、評価の重み・未計算・点差範囲の既存テストも再実行する。ブラウザでは選択色だけでなく、Tabで入る場所、上下移動、Enterの適用対象、候補と相手展開の独立した移動範囲を確認する。
