# 作戦候補の検討・比較・診断

2026-10-15、作業ツリー7e41。ABU 2027英語ルール§3–4、§8–9と現行モデルを照合。画面はこのツリーのVite :5187。終盤174秒の実計算で5候補・共通8手順・実行不可のある展開を確認。

## 代表タスクと配置判断

- 候補を残して再訪：一覧に横比較用チェック、検査側に判断と理由。選択は検査対象、チェックは比較集合として分離する。比較集合は絞り込みで消さず探索単位で保存する。候補行に編集フォームを繰り返さない。
- 同じ相手で比較：選択集合の直下に行=相手・列=候補の比較表。元の一覧と同時参照。構成をまたいだ最小点差をランキングにしない。各セルから根拠の経路へ進む。
- 検査から失敗時刻を確認：選択展開の記録に機体・理由のフィルターと前後移動を置く。実行不可時刻に正確に移動する。分類の組番号は時刻ではない。
- 判断フィルター：表示・出力内で集合を絞る。適用中は解除入口を表の上に残す。判断はユーザー入力で、候補の成功率に読み替えない。

頻度は設計上の仮説。添付カタログのsaved view / selection / contextual inspectorを参照。具体的OSS根拠はui-reference/candidate-expansion-research.mdおよび各担当記録。

## 分担と再巡回

親：候補集合・判断保存・共通型・一覧統合・実ブラウザ検証。比較担当：共通相手マトリクス。診断担当：実行不可記録の選択と時刻移動。調査担当：公式ルール・モデル・PDF画像・Godot固定ソース。

変更前は相手ごとに候補を切替え数値を記憶する必要があり、一覧内に比較集合を保持できなかった。実行不可は文章だけで時刻への操作がなかった。操作時間の改善率は測定しない。

## 第3巡以降の独立担当と統合

初期担当の継続だけにせず、応答ナビゲーション、判断編集、表示収容、集合復帰、証拠解釈、検索精度、狭幅移動、全体の再検討へ新しい担当を投入。計12サブエージェントが順次参加（小領域担当からの再委譲を含む）。各枝は `docs/ui-reference/candidate-*.md` と `docs/candidate-collection-precision.md` に採否・子課題・根拠を記録。

- 応答：共通比較成立と単なるsharedを区別。相手ごとの複数対応、点差順、負点差・実行不可、対象外になった選択の復帰。
- 判断：保存条件へ戻す、削除取消、名前だけ変更、メモ編集の取消復元、Ctrl/⌘+Enter保存。未保存draftの再読込永続化は行わない。
- 証拠：最小値だけでなく裁定幅を抽出。最小でない裁定にある実行不可を見逃さず、赤・青の当事者別に抽出。相手待機からの赤/青/点差の増減を分ける。
- 集合復帰：検索0件から未保存メモへ戻り、同じ候補・同じdraft・textareaフォーカスを実機UIで確認。
- 容量：左列に候補一覧と比較表、右列にInspector。1440px実測で一覧y219/h238、比較y465/h428、Inspector y219から同時可視。表ヘッダーと相手識別列を固定。

## 最終統合で再評価した枝

- 構成指定で候補へ移動する際は、以前の判断・比較中のみの絞込も解除して対象構成を表示する。
- ネストした検索ヘルプのEscは内側だけを閉じて自身のsummaryへフォーカスを戻す（外側は開いたまま）。実ブラウザ確認済み。
- 同じ候補・相手でも裁定が違うA/Bラベルを点差・局面・経路表示で区別。実経路[26,42,38]と[25,31,3]、40点と80点のラベル一致を確認。
- 比較表から「この展開を検査」で同じ候補・裁定をInspectorに引き継ぐ。125対45の対応7、175秒青BRの実行不可、Inspectorフォーカスを実ブラウザで確認。3Dへの適用とは別操作。
- 比較表の選択が検索で隠れた時は対象外表示と復帰操作を出す。古い対象を黙って操作させない。
- 狭幅の領域移動から一覧の選択行へフォーカス復帰。空一覧にも移動でき、空のInspector列を残さない。担当の再委譲で固定見出しと戻り行の重なりも修正。

残る枝：未保存draftのクラッシュ・再読込復旧（現在は明示保存）、非常に多数の候補をDOM描画した際の性能評価。合成500候補の純粋処理計測だけで仮想化は導入しない。モデル外の物理・失敗確率・通信なしの実行可能性は今回も検証しない。

最終検証：全106テスト成功、TypeScriptを含むproduction build成功、git diff --check成功。最終変更後も1440pxで全体横あふれなし。390pxで領域移動・実行不可時刻移動・比較表からの検査引継ぎを確認。ビルドの既存chunkサイズ／動的import警告は残る。
