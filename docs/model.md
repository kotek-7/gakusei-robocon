# 試合モデル

ABUロボコン2027 Rulebook v1.1をNHK学生ロボコン2027の競技ルールとして扱う。試合時間は180秒。原典は`rulebook/Robocon_2027_Rulebook_v1-1.pdf`。

## 局面と採点

局面は時刻、4台の位置と動作、53個の競技物体、ムスティカ取得権、受け渡し履歴からなる。アースは各20個、スカイは共有12個、ムスティカは1個。各物体の所在は一つ。

L1のアースは下段10点・上段20点、スカイ40点。L2は下段20点・上段40点、スカイ80点。アースの得点は置いた側、スカイは上面の色に帰属する。受け渡しは1個5点。ムスティカ設置は250点。自色の完成塔2本のうち1本以上が共有である条件によってムスティカ取得権が成立する。

## 時間と競合

移動は`web/src/engine/model-data.json`の地点と経路に従う。距離を設定速度で割り、秒単位で切り上げる。操作時間も秒単位で切り上げる。全機体の動作を開始した後、次の動作完了時刻へ進める。

同時に同じ資源へアクセスした場合は、試合開始時に指定した赤優先または青優先で処理する。比較画面は両条件を1試合ずつ実行する。途中で優先側が変わる展開は計算対象に含まれない。

## 作戦の実行

建設ロボットの動作区切りで目標を見直す。優先順位はムスティカ、反転、スカイ先行搬送、指定順の建設、搬送加点。資材・能力・到達可能性と残り時間を確認する。輸送ロボットは建設目標に必要な物体を自陣の受け渡しエリアへ運ぶ。方策の受け渡しは床経由。

実行できるコマンドがない機体は1秒待機し、次に判断する。相手の無関係な動作完了を作戦手順の消費として扱わない。青の建設目標は自陣側へ置き換える。

## 解釈と適用範囲

リトライ時の保持物、BRのランプ利用、スカイ移設、反復受け渡しの得点、ムスティカ再取得、取得権の判定方法は条件として明示する。ルール解釈の候補は`model-data.json`に出典とともに保持する。

形状・衝突・姿勢制御・通信・動作失敗・重量・製作工数は計算しない。能力の有無は実装可能性や成功率を証明しない。方策と競合条件を限定した比較であり、全行動空間での最適性や勝率の保証ではない。
