# 有限操作モデル finite-operations-1

競技の連続的な物理運動を有限化したモデル。公式規則そのものではなく、規則と明示的な抽象化に従う。原典と条項の対応は explorer-model-proposal.md および sources.json を参照。

## 状態と遷移

時刻、4機体の操作地点/実行中job/完了時刻/待機履歴、53個の物体ID・所在・支持段・色・搬送加点履歴、永続資格、完成塔履歴、搬送点を保存する。初期物体はEarth各20、共有Sky12、Mustika1。物体は一つの所在だけを持つ。

位置は model/field.py の有限地点と通路。スロープ・階段は折れ線経路。移動時間は経路距離/走行速度を秒へ切り上げ。操作時間も正の秒へ切り上げる。各数値項目は独立なfast / normal / slow。能力採用による速度補正・難易度推定は行わない。

| 操作 | 条件と変化 |
|---|---|
| move | 役割・能力・規則設定が許す隣接経路へ。完了時に地点を更新 |
| pick | 現地点の物体。積載/混載能力と積み上げ支持条件を満たす部分集合。操作開始時に保持へ |
| drop | 自陣受渡し地点で保持物を解放。TRがブロックを解放すると規則設定に従い搬送点 |
| give / receive | TR/BRが同じ受渡し地点で、同じ物体について同期した選択をした場合のみ。完了時に保持者変更 |
| place | BRが該当地点にいる。Earthは2段まで、SkyはEarth2段の上。完了時に解放 |
| flip | BRが該当地点にいて反転能力を持つ。開始時にSkyを保持して採点から除外、完了時に自色で設置 |
| take | 自分の最上段Earth、または移設設定が許すSkyを再把持。支持物の途中抜きは禁止 |
| placeM / takeM | 中央柱の操作地点。奉納は資格と能力が必要。取り外しは規則設定次第 |
| retry | GND開始枠、またはL1進入履歴のあるBRのL1復帰点へ。保持物は規則設定に従う |
| wait / continue | 待機または実行中動作の継続 |

TRの位置はGNDと自陣受渡し、BRは開始進入経路と自陣L1・共有L1/L2。BRのスロープ設定をOFFにすると通常のGND北側移動も許さない。各建設地点の操作にはその層に進入する必要がある。別層から腕だけを伸ばす操作は本版にはない。

双方の行動は同じスナップショットで選ぶ。自陣直接受渡しは同期条件を満たす組だけを列挙する。移動開始時に共有物体や塔を予約しない。取得/反転の接触開始時に競合し、設定に従って両順序または指定優先順の結果を生成する。接触中の同一塔の操作は排他。実機同士の押し合い・衝突力学・審判による接触裁定の全体はモデル化していない。

通常動作は区間完了まで継続。待機は1/2/5/10秒と終了時刻までの待機を候補とし、途中で非待機動作が完了したら解除して再判断できる。一度指定待機が終わった後、環境変化前にさらに短い待機を連結する候補は作らず、次の変化/終了まで待つ選択を残す。これにより2秒を1+1で表す重複を制限する。厳密経路の集計では待機ラベルを取り除き、非待機イベントと正確な時刻が一致する履歴を同一視する。

実行中操作のリトライは1秒ごとに選べる。このため動作中も時刻を1秒ずつ進める場合がある。状態変化も中断選択もない待機区間は次の完了まで飛ばす。終了時刻以後に新規操作は始めず、終了をまたぐ操作の保持物は配置点に含めない。

## 得点と評価

搬送点は加点済み履歴を保存。塔の得点は物体の所在・Earthの帰属・Skyの色から計算。Mustikaは柱へ解放済みの場合に加算。資格はルール設定に応じて同時保有または履歴から永続化する。

勝敗は得点、奉納、Sky数、L2/L1個数の順で比較し、残る同点は審判未決。モデル内でランダム勝者を作らない。

完全展開済みの構成だけ、各局面の双方の行動行列を線形計画で解く。競合結果は不利なものを取る。赤の勝ち保証を第一目的とし、その保証を維持する方針の得点差の保守的下限を併記。得点差は相手の非最善応答も含む下限で、厳密な辞書式均衡の点差とは呼ばない。審判未決を赤敗北/赤勝利として解いた勝ち保証の下限/上限を保持する。SciPyの浮動小数点許容誤差は1e-8。

構造分類の群を閉じた戦略集合とは扱わない。最善応答計算から群外の相手行動を除かない。

## グラフ・分類・件数

継続状態の全属性を正規化JSONでキー化し、同じ構成内だけで統合。開始時刻や進行中操作も含む保守的なキーであり、未来の同値性が不明なものをまとめない。各共同選択と競合結果のエッジを保存する。時刻は必ず増えるので有限DAG。

厳密経路は時刻付きの非待機イベント列、展開群は絶対秒を外して同時イベントのまとまりと順序を残した構造。物体ID・地点IDは保持する。対称性の証明がない入れ替えや異なる順序は縮約していない。同時で独立なイベントは同一バッチ内の正規順にする。

分類階層は構造のイベントバッチを一つずつ伸ばす接頭辞木。作戦は先頭3バッチで固定切断（短い展開は葉）。IDは接頭辞のSHA-256から生成し、構成間で共通。初期の固定切断値3の有用性は実結果を見て改訂する。人が付ける意味的な作戦名は持たない。

標準の勝敗割合は展開群を等重み、群内の厳密経路も等重み。厳密経路を直接等重みとした割合と件数も表示。履歴伝播には独立した上限30,000件があり、上限到達時は統計未完了となる。グラフの完了と履歴集計の完了を区別する。

## 有限化の限界

- 機体寸法/腕軌道・段差の接触・転倒・視認・無通信制御は扱わない。現配置に対する代表機体の操作可能性を能力フラグで与える。
- 受渡し床の物理的な収容密度は個数管理。多量の物体の表示配置は説明用。
- Earth初期配置は2段積み/1段の有限テンプレート。リトライで戻す物体は元領域の個別セル・非積上げ状態に戻す仮定。
- 任意の瞬間での行先変更、待機候補外の開始時刻、偶発失敗は対象外。
- ルール未確定部分の設定は仮説であり、公式FAQの更新に合わせて版を改訂する。
- 完了はこのモデルと設定の範囲に限る。全180秒の全構成の探索が実用時間内に完了する保証はない。
