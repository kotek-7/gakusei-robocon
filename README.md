# 学生ロボコン 作戦ノート

機体条件と作戦を編集し、同じ相手との対戦で得点差と動きを比較するアプリです。NHK学生ロボコン2027の検討用に、ABUロボコン2027 Rulebook v1.1を競技ルールの前提としています。

## 起動

Node.js 22.12以降を使用します。

```sh
cd web
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。

## 検討の流れ

1. 「機体条件」で赤・青それぞれの能力、積載数、走行速度と操作時間を設定します。
2. 「作戦を組む」で建設順、到達段数、反転、ムスティカ取得、スカイ先行搬送を編集します。選択した作戦から手動の別案と、条件を変えた比較用の別案を追加できます。
3. 「比較する」で全作戦を共通の相手と対戦させます。各組を赤優先・青優先の競合処理で1試合ずつ計算します。
4. 表の得点差を選び、その対戦の3D再生と操作履歴を確認します。

計算は一時停止できます。機体条件と作戦、完了した対戦はブラウザに保存され、同じ条件なら未計算の試合から再開できます。条件や作戦を編集すると、その条件での比較に切り替わります。「ファイルに保存」は機体条件と作戦をJSONに書き出します。

## 結果の読み方

得点差は赤の得点から青の得点を引いた値です。各セルの左が赤優先、右が青優先です。この2試合は競合条件への感度を調べるもので、全競合分岐の上下限や実大会での勝率ではありません。

移動経路と操作時間を指定した離散モデルです。機体の衝突回避、姿勢制御、通信、重量、動作の成功率、製作工数は評価しません。任意の行動順や待機時刻まで探索するものではなく、編集した目標と切替条件の方策を比較します。
