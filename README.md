# 学生ロボコン 作戦ノート

機体条件と作戦を編集し、同じ相手との対戦で得点差と動きを比較するアプリです。NHK学生ロボコン2027の検討用に、ABUロボコン2027 Rulebook v1.1を競技ルールの前提としています。

## 起動

Node.js 22.12以降を使用します。

```sh
cd web
npm ci
npm run dev
```

表示されたURLをブラウザーで開きます。最初に「作戦比較」が表示されます。

## 検討の流れ

1. 「機体条件」で自分と相手の能力、積載数、走行速度、操作時間を設定します。条件に名前を付けて保存でき、項目の「この値を変えて比べる」から複数の値を試せます。
2. 「作戦編集」で自分・相手の作戦を編集します。建設順、全目標に共通の段数、反転、ムスティカ取得、スカイ先行搬送を指定します。派生案は変更点を見て、選んだ案を追加します。
3. 「作戦比較」で全作戦、または選択した行・列を計算します。各対戦を赤優先・青優先で計算し、得点差や基準作戦からの変化を確認します。
4. 気になるセルを選び、3Dで機体や塔をクリックします。関連する履歴、得点推移、区間再生を使って動きを確かめます。「広げる」で再生領域を拡大できます。

基準作戦の試合は、同じ時刻・視点で切り替えたり、並べたりできます。気づいた場面には時刻付きメモを残せます。比較表と履歴はCSV、3Dは画像に保存できます。

## 保存と再開

作戦・条件セット・メモはブラウザーに保存します。「ファイル」からJSONの保存・読込ができます。JSONには再生結果を含みません。

計算結果と実行状況も端末に保存します。一時停止やブラウザーの再読込後は「実行一覧」から続きを計算できます。未完了の試合は最初から計算し、完了分を保持します。名前だけの変更や、内容が同じ作戦の複製では結果を再利用します。

## 結果の読み方

得点差は自分・赤の得点から相手・青の得点を引いた値です。表の「競合」で表示する優先側を切り替えます。基準との差分は同じ機体条件・相手・優先側で比較します。二つの優先条件は競合の影響を調べるもので、全展開の上下限や実大会での勝率ではありません。

移動経路と操作時間を指定した離散モデルです。衝突回避、姿勢制御、通信、重量、動作の成功率、製作工数は評価しません。比較するのは編集した目標と切替条件による方策で、任意の行動順や待機時刻を探索するものではありません。

```sh

```
