# 候補作戦群内の混合戦略

比較対象の作戦と同時競合優先順を相手が選ぶ場合に、試合開始時の作戦選択を確率化した最大最小値。相手は分布を知るが、抽選結果を見る前に自分の作戦を決める仮定。実大会の勝率予測ではない。

| 自軍 / 相手 | 期待得点差を目的とする値 | 勝ちを目的とする値 |
|---|---:|---:|
| fast / fast | -45.15点 | 0.333 |
| reference / reference | -149.39点 | -0.000 |
| slow / slow | -0.00点 | -0.000 |
| fast / reference | 441.15点 | 1.000 |
| slow / reference | -377.87点 | -0.000 |

2列の最適化で選ぶ混合比は異なる場合がある。混合比はportfolio.json。定量タイブレークでも決まらない試合は「勝ちではない」と評価する。

この値は有限候補群とマクロモデル内の保証。相手が未列挙の作戦を使う、こちらの方針を見抜いて候補外の切替を行う、経路や衝突が影響する場合の保証はない。
