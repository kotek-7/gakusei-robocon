# STRATA 作戦検討

ABU 2027の作戦を、機体の対応範囲と行動方針から選ぶシミュレーターです。

## 起動

Node.js 22.12以上を使用します。React・TypeScript・Viteによる静的クライアントです。

```sh
npm ci
npm run dev
```

開発時は http://localhost:4173 を開きます。変更は自動反映されます。配信用のビルドは `npm run build`、ビルド結果の確認は `npm run preview`（http://localhost:4183）です。型検査だけなら `npm run typecheck` を使います。

## 一覧から選んで再生する

初期画面は作戦一覧と3Dの同時表示です。作戦を選ぶと0秒から自動再生します。検索・得点の狙い・反転方針で絞り込み、20案ずつ閲覧できます。スマホでは3Dと再生操作を上に固定します。

## 条件・分析を開く

奉納 → 反転条件 → 土台利用 → 建設場所 → 搬送方針の階層を展開して閲覧します。複数群を同時に開けます。「この分類に絞る」はその部分木を表示対象とし、パンくずから上位へ戻せます。

工数上限・活動範囲・BR/TRの登り方は独立した条件として常時変更できます。技術ごとの見積もりは編集でき、ブラウザに保存します。工数は共通技術を一度だけ加算する仮見積もりです。

各群に作戦数・工数幅・得点幅を表示します。右の分布は現在の表示対象を、現在の相手に対して競合優先順2通りで試した結果です。分析画面を開くと計算し、分類と工数の変更には計算済みの結果を再利用します。相手と性能は再生画面で変更できます。

441設定を行動条件の同値性で297作戦に整理しています。作戦の詳細から3D再生や、297相手作戦の評価を開けます。相手は奉納・反転・土台利用で12群に分類し、群内の違いも保持します。「結果を保存」で分類・条件・計算結果をJSONに保存できます。

項目の関係と分類基準は[カタログのデータモデル](../docs/catalog-ui.md)を参照してください。

## 計算範囲

L1限定は代替建設・反転にも適用され、L2には進入しません。建設場所の優先順は、進入できる範囲とは別の指定です。BRのスロープ利用はルール4.3.2との整合確認が必要な仮説として表示します。

CAD経路上の距離・動作時間・資源・得点を計算します。機体の衝突、転倒、走破性、通信、腕の到達範囲、階段の速度低下は判定しません。実機での成立や競技規則への適合は別途確認が必要です。

## 開発

`npm test` で方策の分割、階層分割、Workerの寿命と保存互換性、活動範囲、資源保存、再現性などを検証します。フィールドCADは `../rulebook/field-2027.step`。変更時は `npm run import:field` を実行します。`npm run validate:catalog` は元の441設定×相手3案×優先順2通りの検証です。

技術の採否、状態の所有者、追加先は[構成と依存方向](ARCHITECTURE.md)を参照してください。
